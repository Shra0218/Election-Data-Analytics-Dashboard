# Election Data Analytics & Visualization Dashboard

## Overview

An interactive Business Intelligence solution built using Power BI and Tableau to analyze Indian election data spanning six decades (1962–2024).

The project processes and analyzes over 100,000 election records sourced from ECI, TCPD, Kaggle, and MyNeta datasets to uncover voter behavior, party performance, constituency competitiveness, and demographic trends.

## Key Features

- Processed 100,000+ election records
- Built 3 Power BI dashboards and 1 Tableau dashboard
- Designed a Star Schema data model
- Developed DAX measures for KPI tracking
- Implemented drill-down, filtering, and cross-highlighting
- Performed exploratory data analysis and data cleaning
