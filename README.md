\# Election Data Analytics \& Visualization Dashboard



\## Overview



This project presents an interactive Business Intelligence dashboard developed in Power BI to analyze large-scale Indian election data spanning multiple decades (1962–2024). The objective was to transform complex, multi-source election datasets into meaningful insights through data cleaning, modeling, visualization, and advanced analytics.



The dashboard enables users to explore voting patterns, demographic trends, constituency-level performance, party-wise statistics, and historical election outcomes through interactive visualizations and dynamic filtering capabilities.



\---



\## Dataset



\* Historical Indian Election Data (1962–2024)

\* 100,000+ election records processed

\* Multi-source datasets integrated and standardized

\* Constituency, state, party, candidate, and voter-related attributes

\## Technologies Used



\* Microsoft Power BI

\## Key Features



\### Data Preparation



\* Cleaned and transformed raw election datasets using Power Query.

\* Handled missing values, inconsistencies, and schema standardization.

\* Integrated data from multiple sources into a unified analytical model.



\### Data Modeling



\* Designed and implemented a Star Schema architecture.

\* Created fact and dimension tables for efficient querying and scalability.

\* Established optimized relationships across election entities.



\### Advanced Analytics



Developed DAX measures and calculated columns to analyze:



\* Voter Turnout

\* Vote Share

\* Winning Margin

\* Party Performance

\* Candidate Statistics

\* Regional Trends



\### Interactive Dashboard Components



\* KPI Cards

\* Bar Charts

\* Line Charts

\* Scatter Plots

\* Geographic Maps

\* Trend Analysis Visualizations

\* Comparative State-wise Analysis



\### User Interaction



Implemented:



\* Dynamic Filters

\* Slicers

\* Drill-Down Navigation

\* Cross-Highlighting

\* Multi-Dimensional Analysis by:



&#x20; \* State

&#x20; \* Constituency

&#x20; \* Political Party

&#x20; \* Election Year
